# TSUGI v0.1.2 — First official release

**One home. Many worlds.** Watch · Listen · Read · Collect.

TSUGI is a free, open-source Windows media hub that brings movies, television, anime, music, manga, ebooks and downloads into one cohesive desktop application. Bring your own addons, accounts, servers and local files — four dedicated media spaces, one shared identity.

## 01 / Movies & TV

- **Direct Stremio addon support — no AIOStreams server required.** Paste compatible manifest URLs, manage and reorder addons, and import your configured addon lists from Stremio or Nuvio.
- Optional **AIOStreams and Jellyfin** server connections for existing setups.
- Independent Watch profiles with favourites, queues, history, resume and playback preferences.
- Cinematic browsing, search, episode artwork, seasons, synopsis, cast, ratings, recommendations and metadata enrichment through supported sources and TMDB.
- Dedicated **Anime Hub**, seasonal discovery, anime films, MyAnimeList collection import and reviewed source matching.
- **TVmaze Series Hub** with broadcast and web schedules, genres, regional discovery and Korean dramas.
- Native **mpv** playback, progressive addon stream selection, AIOStreams multiline formatter support, supported audio/subtitle tracks, seeking and version selection.
- Optional **MDBList** lists and ratings, plus **Refract** watchlist and supported completed-watch tracking using personal API keys.

## 02 / Music

- Native **YouTube Music** and **SoundCloud** discovery and playback for supported public sources, alongside compatible public **Eclipse music addons**.
- Local audio library, remembered folders, playlists, favourites, shuffle, repeat, queue management and listening history.
- Three distinct expanded player layouts: **Default**, **Junction** and **Nocturne**, with responsive album artwork, cinematic backgrounds and uncluttered controls.
- Compatible Eclipse Studio layout imports, reactive visualizers, audio-reactive seeking, optional listening mascot, supported audio profiles and EQ.
- **LRCLIB** plain and synchronized lyrics, with manual timing adjustments.
- Keep listening while browsing other media or reading; resume through the shared Up Next workspace.

## 03 / Read

**Mihon and Tachiyomi-compatible extension repositories on Windows.** TSUGI manages a pinned Suwayomi reading runtime behind its own interface, without requiring a separately maintained Java installation or reader server.

- Add trusted repositories, including compatible **Keiyoushi** repositories; install, update and manage individual extensions and source settings.
- Browse and search manga, manhwa and webtoons across installed sources; select sources per title, maintain a categorized library and resume chapters.
- Continuous vertical, single-page and two-page reading, reading direction, zoom, spacing, focus mode and per-title preferences.
- Managed chapter downloads, source migration and supported Mihon/Tachiyomi backup imports.
- MyAnimeList manga XML import with reviewed source assignment; initial MAL/AniList tracker connections and explicit sync tooling.
- Local **EPUB, PDF and CBZ** libraries with bookmarks, reading progress, typography and offline reading.

## 04 / Vault

- **aria2-powered** concurrent direct-file downloads with a persistent native transfer queue, progress, pause, retry and cancellation.
- Individual supported YouTube Music audio exports using **yt-dlp**, with FFmpeg/FFprobe inspection.
- Optional **TorBox** cloud transfer submissions using your own account and API key.
- Completed-file management, storage inventory and direct handoff of local audio, books and comics to Music or Read.

## One workspace

- Cross-media **Up Next**, persistent libraries and resume state.
- Shared visual design inspired by Japanese minimalism, with original illustrations, six dark palettes, independent accents and consistent controls.
- Backup and restore for supported preferences, books, manga and music; scheduled backups and storage management.
- Optional Discord Rich Presence (initial integration; live Discord client operation still needs further validation).
- **Cicada** update notifications, bug reporting, reviewable diagnostics, credits and license information.

## Download & installation

**Windows x64**

[Download Tsugi-windows-x64-setup.exe](https://github.com/G1NYU/TSUGI/releases/download/v0.1.2/Tsugi-windows-x64-setup.exe) · [SHA-256 checksum](https://github.com/G1NYU/TSUGI/releases/download/v0.1.2/SHA256SUMS.txt)

1. Download the installer and verify its SHA-256 against the checksum.
2. Choose all-users installation (Program Files, with UAC approval) or current-user installation (no elevation), and select your destination folder.
3. Launch TSUGI and choose your appearance and media space. Configure the sources you want to use.

No ZIP extraction is required. The installer is unsigned, so Windows may display a warning. Personal data is stored under `%LOCALAPPDATA%\TSUGI`; tested in-place upgrades and uninstall preserve it. Back up important data before upgrading. Uninstall an older installation before changing install mode or location. Existing portable builds retain their separate data. Read prepares its verified runtime on first use.

## Compatibility & release notes

TSUGI does not host or bundle media, subscriptions or third-party addons/extensions. Bring sources you are authorized to use. Compatibility depends on the source, account, region and supported playback format. Third-party reading extensions are executable code; install only from trusted publishers.

Public Eclipse addons are supported; **Eclipse supporter-only account authentication is not included in this release**. Private/premium SoundCloud playback and universal automatic tracker synchronization are not claimed. Live provider and physical-device compatibility may vary.

**Validation:** 479 web tests, 259 native tests (18 intentionally ignored), integrated browser regressions, Windows packaging, both installer scopes and installer checksum round-trip passed. [Successful build](https://github.com/G1NYU/TSUGI/actions/runs/46159377373). Automated tests use controlled fixtures where applicable.
